# Teaboom — карточка товара

Тестовое задание: верхняя часть карточки товара **Ананасовый улун** для [teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

```bash
# вариант 1 — Запуск локали
npm start
```

Страница будет на [http://localhost:3000](http://localhost:3000).

## Разработка стилей

Нужен Node.js ≥ 18 (рекомендуется 20/22).

```bash
npm install
npm run build:css   # однократная сборка
npm run watch:css   # watch-режим
```

## Что реализовано

- изображение, название, категория, фасовки, артикул, цены, кнопка «В корзину», описание
- переключение фасовки меняет цену, старую цену, артикул и active-состояние
- hover у кнопки «В корзину» в стилистике Teaboom (чёрный фон + жёлтый текст)
- адаптив: 1440 / 768 / 375
- анимации: появление карточки, zoom фото, смена цены, badge скидки, feedback кнопки
